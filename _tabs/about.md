Hi, I'm **Juan Vásquez**, a senior Ruby on Rails engineer from Oaxaca, México, working fully remote.

I'm the engineer teams bring in when a Rails application has fallen behind. For 10+ years I've
built and modernized production Rails apps: version upgrades from as far back as Rails 2 up to the
latest, multi-tenant architecture, background jobs and the performance work that keeps an app
alive. Currently at [OmbuLabs / FastRuby.io](https://www.fastruby.io), where I've worked with a
dozen client companies across payments, healthcare, media and education.

I contribute to the tools the Rails community upgrades with:

- [Ruby on Rails](https://github.com/rails/rails/pulls?q=is%3Apr+author%3AJuanVqz+is%3Amerged)
  itself, including the [PWA offline fallback page](https://github.com/rails/rails/pull/57184)
  that ships in every new Rails app
- Leading contributor to
  [claude-code_rails-upgrade-skill](https://github.com/ombulabs/claude-code_rails-upgrade-skill),
  an open-source Claude Code skill that automates Rails upgrades
- [next_rails](https://github.com/fastruby/next_rails) and
  [RailsBump](https://github.com/railsbump/app), the tools teams plan upgrades with
- Maintainer of the Spanish (es) locale of [MDN Web Docs](https://github.com/mdn/translated-content)
- [Alacritty Themes](https://github.com/alacritty/alacritty-theme)

I also design, ship and still run my own multi-tenant Rails applications in production, which is
where I learned that owning something is a different discipline from delivering it.

This blog is where I share practical things from day-to-day work: asset pipelines, upgrades,
debugging, Docker, Git, Rails patterns. The kind of stuff I wish I'd found when I needed it.
